Most of what lives here is a **complete application rather than an exercise**. **Marginalia** is a
writing platform in two halves — a Flutter client and a Django REST API on Postgres — deployed,
documented with Swagger, and covered by **109 API tests + 35 widget tests**. **HireHorizon** began as
a Flask blog and was rewritten as five Django apps carrying feeds, follows, messaging and notifications.

The other half is applied ML: Keras CNNs that ended up **behind Flask forms instead of stopping at the
notebook**, plus scikit-learn work on sonar, spam and diabetes data. By day I work on geospatial data
pipelines — satellite imagery and LiDAR feeding HD maps for autonomous vehicles.

## How I work — the forward-deployed loop

<div align="center">
<img src="./assets/fde-loop.svg" width="100%" alt="Animated loop: client problem, Python service, model and data, deployed, then feedback back to the client">
</div>

I gravitate to the unglamorous parts that decide whether a thing works *in the field*:

- 📮 **Host blocks SMTP?** Marginalia sends sign-up codes over an HTTP mail API instead.
- 🐘 **Free-tier Postgres dropping connections?** Pooler-aware DB settings, picked on purpose.
- 📱 **No server budget?** HireHorizon self-hosts from an Android phone under Termux behind a Cloudflare tunnel.
- 🧩 **New file format next month?** File Diff Engine keeps parsers in a registry — one function, one dict entry.
